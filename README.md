## 🚀 Projeto em destaque

### 💰 [Meu Financeiro](https://github.com/Hug4oo/MEU-FINANCEIRO)

App de finanças pessoais (web e PWA) que responde uma pergunta: **quanto sobra no dia 15 e no dia 30?**  
Está no ar, com usuários reais testando.

🔗 **Demo:** [meu-financeiro-delta-five.vercel.app](https://meu-financeiro-delta-five.vercel.app)

- Dois ciclos de pagamento independentes, parcelamentos e contas recorrentes
- Dados isolados por usuário com **Row Level Security** e **31 testes de isolamento**
- **39 testes automatizados** na lógica financeira
- Valores em centavos inteiros, para evitar erro de arredondamento
